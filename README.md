# 🕹️ Bit Smash

A modern, mobile-responsive Atari Breakout clone built with **vanilla HTML5 Canvas, CSS3, and ES6 JavaScript**. Features classic arcade mechanics paired with a retro CRT monitor aesthetic.

<img src="https://github.com/user-attachments/assets/748dc7b0-702c-41b3-ae86-abb0226236f5" width="708" alt="Bit Smash Preview" />

---

## ✨ Features

* **ES6 Object-Oriented Architecture:** Modular classes for `Game`, `Ball`, `Paddle`, and `Brick`.
* **Retro CRT FX:** Pure CSS CRT screen overlay with realistic scanlines, phosphor flicker, and glass vignette.
* **Responsive Touch Controls:** Full mobile drag-and-drop support with dynamic viewport scaling.
* **Keyboard & Mouse Support:** Smooth controls for desktop players.
* **Zero External Dependencies:** Built with pure vanilla tools—no heavy frameworks or libraries required.
